# Cache Module
Cache Module은 Peauty 시스템의 공통 캐싱 기능을 제공하는 모듈입니다.
이 모듈은 Peauty 시스템의 API 모듈이 캐싱 관련 기능을 직접 구현하지 않고도 동작할 수 있도록 지원합니다.
Cache Module의 주요 책임은 API 모듈의 캐싱 관련 종속성을 제거하여 API 모듈이 본연의 기능에만 집중할 수 있게 하는 것입니다.

## 주요 기능
- **데이터 캐싱 처리**: 인메모리 캐싱을 지원하고, 데이터 유형에 따른 캐싱 전략과 TTL 관리 기능을 제공합니다., 현재 지원하는 DBMS 는 Redis 입니다.
- **분산 락 제공**: 동시성 제어가 필요한 작업에 대해 분산 환경에서의 락 메커니즘을 제공합니다. 추후 서비스 확장 시 도입 예정입니다.
